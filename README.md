# Lab2 Team Project – Hello World

A simple web page that shows "Hello, World!" with an image of the Earth.

## Structure

```
index.html        # the page
images/earth.svg  # the image
```

## Run

Open `index.html` in any web browser, or serve the folder locally:

```
python -m http.server 8000
```

Then go to http://localhost:8000.
